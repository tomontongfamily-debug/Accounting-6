Cashier does not need to calculate liters. Just copy the gray Previous Shift Closing, type the correct Current Closing from the pump register, and let the system calculate Liters Sold automatically.
No gasoline / closed station: If there were no sales, type the same number in Current Closing as Previous Shift Closing. Example: before 1000, after 1000 = 0 L. This is allowed.
Never type lower than previous closing. Example: before 1000, after 990 is wrong because it creates negative liters.

6. If Fuel Price Changes During Shift

The manager handles the price-change entry in the manager page. The cashier's job is to help record the pump register reading at the exact time the price changed.

SituationCashier should doCashier should not do
Fuel price changes during the shiftWrite down the exact time and pump register reading for each affected product/nozzleDo not change the manager price in the app
Manager asks for price-change readingGive the pump reading at the price-change time, not the final closing readingDo not guess the reading later
No price change during shiftDo nothing in this area; continue normal current closing entryDo not invent a price-change entry
Example: If Regular price changed at 1:30 PM, cashier should record the Regular pump register reading at 1:30 PM. The manager uses that reading to split sales before and after the new price.

8. Deductions, FuelTech Pay, PO/PR

FuelTech Pay Total

Enter the total non-cash payment amount together: card, GCash, Paymaya, and similar payments.

Points Withdrawn

This is based on Cash Redemption + Fuel Redemption. Do not manually invent this number if shown as read-only.

Cash redemption / fuel redemption

Enter redemption only in the correct redemption fields if they appear in the app. Points Withdrawn is based on these redemptions.

Bank deposit is not cashier input

Do not put bank deposit amount in deductions, PO, PR, or FuelTech Pay. Manager handles bank deposits.

Important: End-of-Shift Cash Count does not replace expected cash and does not replace bank deposit. It only checks physical counted cash against the system expected cash on hand.

9. Request Date Correction

Use this if the cashier needs to correct a past date or shift. It opens only after admin approval.

Select correct report date and shift

Choose the old date/shift that needs correction.

Type reason

Example: "Wrong Regular reading typed in Shift 2."

Press Send Request to Admin

Wait for admin approval before editing that report.

Do not use correction request to skip today's report. It is only for fixing a real wrong date/shift after admin approval.
