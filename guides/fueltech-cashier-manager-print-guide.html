1. What The System Does

Cashier records the shift

The cashier enters pump closing readings, underground tank readings, deductions, PO/PR, oil sales, Coke ending, and then submits the shift report.

Manager controls prices and deposits

The manager enters fuel prices and bank deposits. If a deposit is wrong, the manager requests change/removal and waits for admin approval.

How To Understand This

Gray number Previous Shift Closing

Read-only. Do not change. It comes from the last submitted shift.

White input Current Closing

Cashier types the current pump register reading here.

Formula Current - Previous

This becomes liters sold.

Correct examples

  • Previous 1000, Current 1015 = 15 L sold.
  • Previous 1000, Current 1000 = 0 L sold. This is allowed if no gasoline/no sales.
  • Decimal numbers like 1015.50 are allowed.

Blocked example

  • Previous 1000, Current 990 = not allowed.
  • This means negative liters and the report should not be submitted.
Closed station / no gasoline: If there were no sales, input the same number in Current Closing as Previous Shift Closing. The system will count it as 0 liters sold.

Before Typing

  • Check shift time.
  • Enter real cashier name.

Pump Reading Rule

  • Type Current Closing only.
  • Gray Previous Closing is read-only.
  • Current lower than previous is wrong.
  • Same number is OK for zero sales.

Zero Sales / No Gasoline

  • Previous: 1000
  • Current: 1000

Sticker Reminders - Manager

Print this page and cut into small reminders for the manager area.

Fuel Price Setup

  • Set effective date.
  • Choose Daily unless one shift only.
  • Enter Premium, Regular, Diesel.
  • Press Confirm Fuel Prices.

Bank Deposit Rule

  • Deposit Date = day money was deposited.
  • Sales Date Covered = shift sales day.
  • Covers = shift/s included.

Combined Deposit

  • One bank deposit covering many shifts?
  • Enter it once.
  • Pick Shift 2 + Shift 3 or All Shifts.

If Deposit Is Wrong

  • Do not secretly edit.
  • Press Request Change or Removal.
  • Wait for admin approval.
